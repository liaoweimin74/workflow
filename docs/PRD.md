# 工作流平台 PRD

> 版本：v1.0  
> 日期：2026-08-01

---

## 1. 项目背景与目标

基于 Flowable 最新版本开发一个完整的工作流系统，包含前后端应用。系统需提供工作流设计、表单设计、流程执行引擎三大核心能力，并能方便地集成到其他业务系统中。

---

## 2. 技术栈

| 层级 | 技术 |
|---|---|
| 后端 | Spring Boot + Flowable |
| 前端 | Vue 3 + Element Plus |
| 数据库 | MySQL |
| 构建 | Maven（多模块）|

---

## 3. 功能需求

### 3.1 流程设计器

用户在浏览器中通过拖拽方式设计 BPMN 2.0 流程图。

- 支持 BPMN 2.0 规范的主流元素：开始/结束事件、用户任务、网关、子流程、泳道等
- 支持节点属性配置，各节点类型属性如下：

  **开始事件：** 名称、关联表单、发起人权限

  **用户任务（核心）：**
  - 基本信息：名称、描述
  - 审批人设置：审批人类型（指定用户/指定角色/部门负责人/发起人自选/表达式）、审批人值、多人审批方式（会签/或签）
  - 表单：关联表单、表单字段权限
  - 时限：超时时间、超时动作（提醒/升级）
  - 操作：允许驳回、允许加签、允许转签

  **网关（排他/并行/包含）：** 名称、默认流转

  **定时器事件：** 定时类型（固定时长/指定时间/重复周期）、定时值

  **子流程：** 名称、调用的流程、传入/返回变量映射

  **结束事件：** 名称

  **连线：** 条件表达式、默认流转标记、描述
- 支持连线条件编辑
- 支持导入/导出 BPMN XML
- 支持流程模拟预览
- 支持撤销/重做
- 流程定义支持分类管理
- 支持基于已有流程定义复制创建新流程
- 流程设计器应呈现现代美观的视觉风格

#### 3.1.1 后端业务逻辑配置

流程节点应支持配置后端业务逻辑，在节点进入或完成时自动执行。支持三种方式：

- **调用外部 API**：配置 HTTP 请求调用外部系统接口，支持请求参数引用流程变量、返回值写入流程变量、异常处理策略（忽略继续/中断流程）
- **调用本系统服务**：选择已注册的 Spring Bean 和方法，支持流程变量与方法参数的映射
- **执行脚本**：编写 Groovy/JavaScript 代码片段在引擎中执行

后端逻辑可在用户任务、开始事件、结束事件等节点上配置，支持在一个节点上配置多个逻辑按顺序执行。

### 3.2 表单设计器

用户在浏览器中通过拖拽方式构建表单。

#### 3.2.1 组件类型

**核心组件：**
- 单行文本、多行文本、数字输入
- 下拉选择（单选/多选）
- 单选、多选
- 日期、日期范围
- 文件上传

**扩展组件：**
- 人员选择、部门选择
- 数据引用组件（从其他业务表或表单选取数据）
- 子表/表格（动态行、多列字段）
- 嵌套表单
- 分组容器、分割线
- 自动编号、富文本、开关、评分、地址

#### 3.2.2 组件扩展

- 支持开发者注册自定义组件，无需修改核心代码
- 前后端扩展机制对称

#### 3.2.3 属性配置

- 每个组件的可配置属性按组件类型动态展示
- 包括基本属性、校验规则、高级属性

#### 3.2.4 事件脚本

- 组件支持在前端执行 JavaScript 脚本
- 脚本事件包括：初始化、值变化、失去焦点、可见性变化
- 脚本可控制其他字段的值、显隐、必填、禁用等
- 脚本在沙箱中安全执行

#### 3.2.5 可视化规则

- 常用联动场景（显隐、计算、选项过滤）提供可视化配置
- 复杂场景通过 JS 脚本兜底

#### 3.2.6 表单字段权限

- 第一期：字段区分为"创建时填写"和"审批时查看"
- 后续：细粒度角色控制

### 3.3 流程执行引擎

#### 3.3.1 基础能力

- 流程定义部署、激活、挂起
- 流程实例启动、挂起、恢复、终止
- 任务签收、完成、转办、委派
- 流程变量管理
- 流程图高亮跟踪

#### 3.3.2 会签与或签

- 会签：多个审批人全部通过才通过
- 或签：任一审批人通过即通过

#### 3.3.3 加签与转签

- 加签：审批人临时增加其他审批人
- 转签：审批人将审批权转给他人

#### 3.3.4 驳回

- 第一期：驳回到发起人，发起人修改后重新提交
- 后续：驳回到任意历史节点

#### 3.3.5 催办

- 发起人可手动催办当前审批人
- 同任务有催办频率限制

#### 3.3.6 超时处理

- 可配置超时规则
- 超时后自动发送提醒
- 支持超时升级（转给上级或指定人）

### 3.4 REST API

系统通过 REST API 对外提供能力，供其他业务系统集成。

#### 核心 API 分组

| 分组 | 说明 |
|---|---|
| 流程定义 | 流程的 CRUD、部署、版本管理 |
| 流程实例 | 启动、终止、挂起/恢复、高亮图 |
| 任务 | 待办/已办、审批、转办、委派、催办 |
| 表单定义 | 表单 CRUD、发布 |
| 表单实例 | 表单数据提交、查询 |
| 数据源 | 通用数据查询接口 |
| 通知 | 站内信查询、已读 |
| 身份认证 | 登录、JWT |
| 用户/组织 | 用户、角色、部门 |
| 系统管理 | 租户管理、审计日志 |
| 统计 | 流程统计、任务效率 |

### 3.5 多租户

- 系统需支持多租户，不同租户间的流程数据相互隔离
- 租户信息通过请求头传递

### 3.6 用户权限与组织架构

#### 3.6.1 角色体系

| 角色 | 范围 | 职责 |
|---|---|---|
| 超级管理员 | 平台级 | 管理所有租户 |
| 租户管理员 | 租户级 | 管理本租户用户/角色 |
| 流程设计者 | 租户级 | 设计流程和表单 |
| 普通用户 | 租户级 | 发起流程、处理任务 |

#### 3.6.2 用户/组织对接

- 第一期：系统内置用户、部门、角色管理
- 后续：业务系统通过回调接口提供用户/组织数据，系统预留对接接口

### 3.7 通知

- 系统内置站内信通知中心
- 通知场景：新任务、催办、超时、超时升级、审批结果、加签
- 通知模板可配置
- 预留外部通知渠道接口（邮件、企微、钉钉等）

### 3.8 审计日志

- 记录所有关键操作：流程/表单的创建、编辑、删除、部署/发布、流程实例操作、任务操作、系统管理操作
- 支持按租户、操作人、操作类型、时间范围查询

### 3.9 统计与监控

- 第一期：基础统计（流程热度、任务效率、个人绩效、实时概览）
- 后续：SLA 监控、瓶颈分析、趋势分析、可视化仪表盘

### 3.10 流程版本管理

- 同一流程多次部署自动递增版本号
- 运行中的实例不受新版本影响
- 支持版本回滚

## 5. 分阶段计划

### 第一阶段：核心框架 + 引擎集成

搭建项目骨架，集成 Flowable 引擎，实现基础 REST API，跑通流程全链路。

### 第二阶段：管理后台 UI

实现 Vue 3 前端，包括流程管理、任务管理、流程跟踪、用户登录、通知中心、审计日志。

### 第三阶段：BPMN 设计器

实现浏览器端拖拽式流程设计器，支持流程设计、保存、部署、模拟。

### 第四阶段：表单设计器

实现拖拽式表单设计器，支持表单与流程变量打通。

### 后续阶段

| 功能 | 优先级 |
|---|---|
| 扩展表单组件（人员选择、数据引用、子表等） | 高 |
| 驳回任意节点 | 高 |
| 邮件/企微/钉钉通知 | 中 |
| SLA 监控/仪表盘 | 中 |
| 表单字段细粒度权限 | 中 |
| 版本对比视图 | 低 |
| K8s 部署 | 低 |
| 国际化 | 低 |
