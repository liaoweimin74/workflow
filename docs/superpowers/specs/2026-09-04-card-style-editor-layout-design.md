# 卡片与字段样式编辑器布局修正设计

## 1. 修正目标

优化卡片样式配置和字段高级设置的空间利用率、对齐和编辑效率：

- 删除卡片预设列表中的重复“蓝色科技”选项；
- 条件样式从规则卡片改为紧凑表格；
- 样式脚本摘要改为“可直接输入 + 右侧编辑图标”的编辑框；
- 编辑图标打开 CSS 脚本弹窗，弹窗与页面输入保持同步；
- 字段高级设置移除多余分组标题和分割横线；
- 字段“始终生效样式”改名为“样式脚本”；
- 字段基础 class 增加明确 label；
- 表单使用顶部 label 和 24 栅格，同组字段并排，不同语义组独占换行。

## 2. 通用脚本编辑框

整体样式和字段样式共用 `StyleScriptInput` 交互组件，视觉结构为：

```text
样式脚本
┌────────────────────────────────────────────┐
│ color: #303133;                         ✎ │
│ font-weight: 600;                         │
└────────────────────────────────────────────┘
```

要求：

- 文本区域支持直接输入和修改；
- 右侧显示编辑图标按钮；
- 点击编辑图标打开 CSS 脚本弹窗；
- 弹窗确认后回写页面输入框；
- 页面输入框修改后，弹窗打开时显示最新文本；
- 空内容显示“未设置样式脚本”；
- CSS 内容只填写声明块，不填写选择器。

弹窗标题和作用范围根据上下文显示，例如：

```text
编辑样式脚本
作用范围：整张卡片
```

或：

```text
编辑样式脚本
作用范围：当前字段“状态”
```

## 3. 卡片整体样式配置

### 3.1 页面结构

```text
卡片样式配置

预制样式
[ 默认 · 标准网格卡片                         ▼ ]

样式脚本
┌────────────────────────────────────────────┐
│ background-color: #ffffff;              ✎ │
│ border-radius: 8px;                       │
│ padding: 16px;                            │
└────────────────────────────────────────────┘

基础 class
[ el-card is-hover-shadow process-card         ]
提示：多个 class 使用空格分隔，不需要输入“.”。

条件样式
┌──────┬────────────────────┬──────────────────────┬──────────────────┬──────┐
│ 启用 │ 条件表达式 [?]     │ 命中样式脚本         │ CSS Class        │ 操作 │
├──────┼────────────────────┼──────────────────────┼──────────────────┼──────┤
│ ✓    │ $row.status ===    │ background-color... ✎│ status-error     │ 删除 │
│      │ '异常'             │                      │                  │      │
└──────┴────────────────────┴──────────────────────┴──────────────────┴──────┘

[+ 添加条件样式]

[取消] [确定]
```

### 3.2 预制样式

下拉选项必须唯一，包含 6 个主题：

```text
默认 · 标准网格卡片
紧凑 · 小号间距精简
宽松 · 大间距舒适留白
深色 · 暗色主题
无边框 · 极简透明
蓝色科技 · 霓虹科技风格
```

“蓝色科技”只能出现一次，内部主题值统一使用 `techBlue`。

选择预制主题后，主题 CSS 自动填入“样式脚本”编辑框，用户可以继续直接编辑或打开弹窗编辑。

### 3.3 条件样式表格

条件规则不显示名称，不使用单独规则弹窗。表格列为：

- 启用开关；
- 条件表达式输入框；
- 命中样式脚本编辑框；
- CSS Class 输入框；
- 删除操作。

条件表达式标签后放置 `?` 悬浮帮助：

```text
请输入 JavaScript 条件表达式。

可用变量：
$row 当前数据行
row 当前数据行

示例：
$row.status === '异常'
$row.amount > 10000
$row.priority === '高' && $row.status !== '完成'

表达式返回 true 时，应用本规则样式。
```

条件规则中的 CSS 脚本编辑框与基础脚本编辑框相同：可以直接编辑，也可以点击右侧编辑图标打开弹窗。

## 4. 字段高级设置

### 4.1 删除视觉分组

移除以下分组标题及分割横线：

- 动态内容；
- 列样式；
- 字段样式；
- 单元格点击事件（配置后优先于整表级点击）。

内容配置、字段显示、样式和点击动作仍保持逻辑上的连续顺序，但通过布局、间距和字段排列区分，不使用多条 `el-divider`。

### 4.2 页面结构

所有表单项采用顶部 label：

```text
内容模式
[ 表达式 ] [ 模板 ] [ 无 ]

表达式
[ $row.name + '(' + $row.dept + ')'         ]

角色                         值类型
[ 普通字段                ▼ ] [ string     ▼ ]

对齐方式                     显示标签
[ 左对齐                  ▼ ] [ 开启          ]

标签位置
[ 左侧                    ▼ ]

样式脚本
┌────────────────────────────────────────────┐
│ color: #303133;                         ✎ │
│ font-weight: 600;                         │
└────────────────────────────────────────────┘

基础 class
[ status-value text-primary                    ]
提示：多个 class 使用空格分隔，不需要输入“.”。

条件样式
┌──────┬────────────────────┬──────────────────────┬──────────────────┬──────┐
│ 启用 │ 条件表达式 [?]     │ 命中样式脚本         │ CSS Class        │ 操作 │
├──────┼────────────────────┼──────────────────────┼──────────────────┼──────┤
│ ✓    │ $value === '异常'  │ color: #f56c6c;   ✎ │ status-error     │ 删除 │
└──────┴────────────────────┴──────────────────────┴──────────────────┴──────┘

[+ 添加条件样式]

点击动作
[+ 增加动作]

[取消] [保存]
```

“始终生效样式”标签统一改为“样式脚本”。字段基础 class 必须有独立的“基础 class” label。

### 4.3 字段条件帮助

```text
请输入 JavaScript 条件表达式。

可用变量：
$value 当前字段值
$row 当前数据行
row 当前数据行

示例：
$value === '异常'
$row.status === '异常'
$row.amount > 10000

表达式返回 true 时，应用本规则样式。
```

## 5. 栅格与对齐规则

采用 24 栅格，label 与控件上下排列：

```css
.cfg-row {
  display: grid;
  grid-template-columns: repeat(24, minmax(0, 1fr));
  gap: 16px;
}
```

布局规则：

| 内容 | 栅格 |
|---|---:|
| 预制样式 | 24 |
| 样式脚本 | 24 |
| 基础 class | 24 |
| 角色 | 12 |
| 值类型 | 12 |
| 对齐方式 | 12 |
| 显示标签 | 12 |
| 标签位置 | 12 |
| 条件样式表格 | 24 |
| 点击动作 | 24 |

允许同一行并排的内容必须属于同一语义组：

- 角色 + 值类型；
- 对齐方式 + 显示标签。

以下内容必须独占整行：

- 样式脚本；
- 基础 class；
- 条件样式表格；
- 点击动作；
- 预制样式。

不为了填满空间而并排放置不同语义组的控件。

## 6. 数据和行为约束

- 卡片整体规则作用于整张卡片；
- 字段规则作用于当前 CELL/字段元素；
- 卡片整体条件使用 `$row`；
- 字段条件使用 `$value`、`$row` 和 `row`；
- 所有启用且命中的条件规则按顺序合并；
- 后命中的同名 CSS 属性覆盖前面的属性；
- className 支持多个空格分隔的 class；
- className 不要求输入 `.`；
- 条件规则无名称；
- 条件表达式直接在表格单元格编辑，不单独弹窗；
- CSS 脚本只通过脚本编辑框/脚本弹窗编辑。

## 7. 验收标准

- 卡片配置下拉中“蓝色科技 · 霓虹科技风格”只出现一次；
- 卡片条件样式使用紧凑表格；
- 字段条件样式使用紧凑表格；
- 样式脚本控件可以直接输入；
- 样式脚本控件右侧有编辑图标；
- 点击编辑图标可以打开脚本弹窗；
- 页面输入和弹窗输入保持同步；
- 字段界面没有上述四个分组标题和分割横线；
- 字段标签显示为“样式脚本”；
- 字段基础 class 有明确 label；
- 24 栅格布局中 label 和 input 上下排列；
- 同组字段可以并排，不同组字段不会被强行放在同一行；
- 所有脚本编辑框和条件表格列左右边缘对齐；
- 不影响卡片、表格整体和 CELL 样式渲染逻辑。
