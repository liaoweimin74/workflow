   528→   528→## 6. 迁移关键注意点
   529→   529→
   530→   530→1. **SSE 是唯一非 JSON 端点**：`GET /api/v1/notifications/sse`（produces text/event-stream，返回 SseEmitter 长连接），permitAll + `?token=` query 认证且强制 access_token 类型；Node 版需实现等价 SSE 通道（事件如 `new-message`），并处理连接注册/推送/断连。
   531→   531→2. **放行路径仅 2 条**：`POST /api/auth/login` 与 SSE 端点；其余全部需 JWT。且全库无 `@PreAuthorize`——管理端权限是代码内 `requireAdmin()`、页面数据出口是 `PageAccessGuard`（404/403 语义 + admin 放行），Node 版必须以中间件复刻这两类检查，不能只做"登录即可"。
