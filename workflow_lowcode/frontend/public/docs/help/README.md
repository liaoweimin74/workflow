# 项目帮助

本帮助分为两册，面向两类读者：

| 手册 | 读者 | 目的 | 入口 |
| --- | --- | --- | --- |
| 开发手册 | 应用开发者 | 学会用低代码平台搭建应用：表单、页面、数据源、逻辑流、工作流、模块与物料 | [dev/README.md](dev/README.md) |
| 管理手册 | 系统管理员 | 掌握日常系统管理：用户、角色、组织、字典、消息、流程运维、AI 配置 | [admin/README.md](admin/README.md) |

> 标注 **【规划中】** 的能力当前版本尚不可用或仅有部分入口，请以实际界面为准。

## 开发环境

平台由前后端两个工程组成（仓库内 `backend/` 与 `frontend/` 目录），本地开发环境如下：

| 端 | 技术栈 | 版本要求 | 运行端口 | 启动方式 |
| --- | --- | --- | --- | --- |
| 后端 | Java + Spring Boot + Flowable 工作流引擎 | JDK 21、Maven 3.9+；Spring Boot 4.0、Flowable 8.0 | 8080 | 在 `backend/` 下执行 `mvn clean spring-boot:run` |
| 前端 | Vue 3 + TypeScript + Element Plus + Vite + Tailwind CSS | Node.js 20+（建议 LTS）、pnpm | 3000 | 在 `frontend/` 下执行 `pnpm install`，再 `pnpm dev` |
| 数据库 | MySQL（兼容 MariaDB） | 8.x | 3306 | 无需手工建表：首次启动 Flyway 自动执行建表迁移 |
| 缓存 | Redis | 6.x+ | 6379 | 登录态与部分缓存依赖，需在本地启动 |

前后端端口约定：前端开发服务器把 `/api` 请求代理到后端 8080；浏览器访问 `http://localhost:3000` 即可使用完整系统。

## 开发前的准备

1. **装好基础环境**：按上表安装 JDK 21、Maven、Node.js + pnpm、MySQL、Redis，并确认服务已启动。
2. **启动平台并登录**：先后端后前端，浏览器打开 `http://localhost:3000`，用管理员账号登录，确认表单、页面、流程等基础功能可正常打开。
3. **熟悉平台界面**：花半小时逛一遍 [02 章 新手入门](dev/02-新手入门.md)，对照界面认识表单设计器、页面设计器、逻辑流、流程设计器四个核心工具。
4. **明确需求落在哪个圈**：先读 [09 章 9.1](dev/09-自定义开发.md#9.1) 的判断表——大多数需求零代码就能完成，确认确实圈外再动手写代码。

## 需要了解的知识

按你想做的事分层，不必一次学全：

| 你要做的事 | 需要的知识 |
| --- | --- |
| 零代码搭建应用（表单、页面、逻辑流、审批流） | 不需要编程基础；读懂开发手册 01–08 章，熟悉平台各设计器的操作即可 |
| 前端自定义（手写页面 / 页面物料） | Vue 3 组合式 API、TypeScript、Element Plus 组件库、Vite 工程基本操作、前端路由（见 [09 章 9.2–9.3](dev/09-自定义开发.md#9.2)） |
| 后端自定义（业务表单钩子 / 后端 Bean / 监听器） | Java、Spring Boot（Bean 注入与事件机制）、SQL；涉及流程扩展还需了解 Flowable 的流程实例、任务、监听器等基本概念（见 [09 章 9.4](dev/09-自定义开发.md#9.4)） |
| 系统管理（用户、角色、字典、流程运维） | 不需要编程基础；读管理手册即可 |

> 动手写代码前，建议先过一遍 [09 章末尾的自检清单](dev/09-自定义开发.md#9.5)，避免把零代码能做的事硬写成代码。
