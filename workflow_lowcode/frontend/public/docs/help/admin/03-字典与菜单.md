# 03 字典与菜单

## 3.1 字典管理（系统管理 → 字典管理）

字典解决「下拉选项谁来维护」的问题：页面布局为**左栏字典类型导航 + 右栏字典项表格**。

维护步骤：

1. 左栏新建**字典类型**（如 `fault_type 故障类型`，编码建议语义化小写）；
2. 选中类型，右栏维护**字典项**：标签（显示给用户）、值（存库）、排序、启停；
3. 开发侧在表单设计器用「字典选择」组件绑定该字典编码后，本页的增删改即时生效，无需重新发布表单。

调整顺序（推荐用拖动）：

- 每行最左侧有一个十字箭头把手，**按住把手**把该行拖到目标行上：落在目标行的**上半段**排到它前面，落在**下半段**排到它后面，行上会出现蓝色插入线提示落点；
- 松手后即刻保存（等价于批量改「排序」字段），下拉选项与业务表单里的顺序随之生效；
- 没有「字典项排序」权限时不显示把手，可仍用编辑弹窗里的排序数字调整；
- 搜索过滤或翻页后只拖动当前可见的几行也安全：未显示的字典项保持原有位置不动。

注意事项：

- 字典项的「值」一旦有业务数据引用，改名会破坏存量数据，只增不删、停用代替删除；
- 排序决定下拉/展示顺序，用拖动（或排序字段）调整，不要改值；
- 字典项支持启停：停用后新表单不再出现该选项，历史数据展示不受影响；
- 「创建时间」列默认不显示，需要核对录入时间时勾选右栏卡片标题行最右侧的**显示创建时间**。

## 3.2 菜单管理（开发管理 → 菜单管理）

管理员日常用到的三类操作：

1. **微调入口位置**：树表上拖拽调整菜单的层级与顺序（改标题、图标同理）。注意路由 path 是前端静态注册的，**不要随意改 path**，否则历史书签/已挂接引用会失效；
2. **清理失效入口**：页面/物料删除后可能残留无效菜单，在这里定位并删除（页面侧解除挂接是首选，见开发手册 08.2）；
3. **核对权限标识**：新建菜单时权限标识要和后端一致（页面类为 `page:read:{页面key}`），错了会出现「菜单可见但访问 403」。

目录与按钮的增删改权限在「开发管理」权限组下，纯管理员账号若看不到本菜单，请让平台开发授权或由开发侧处理。

## 3.3 常见问题

**Q：字典加了新选项，表单里没出现？**
确认表单组件绑定的是字典编码而非静态选项；确认字典项是启用状态；前端刷新一次即可生效。

**Q：菜单改了排序，用户没变化？**
菜单树有缓存，用户重新登录或刷新页面后生效。

**Q：能批量导入字典/用户吗？**
当前版本以页面逐条维护为主，大批量初始化建议联系平台开发用脚本导入，导入手工核对一遍。
