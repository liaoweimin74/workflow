# 卡片整体与字段样式编辑器设计

## 1. 目标与范围

为卡片列表提供统一、易理解的样式编辑方式，覆盖：

- 卡片整体样式：控制整张卡片；
- 字段级样式：只控制当前字段；
- 无条件样式：始终生效；
- 条件样式：根据当前行数据判断后生效；
- CSS 脚本：页面内显示摘要，点击后使用弹窗编辑。

本设计面向尚未稳定运行的系统，不保留旧样式字段或旧配置格式的兼容逻辑。

## 2. 统一样式规则模型

整体样式和字段样式使用相同的规则概念：

```ts
interface StyleRule {
  enabled: boolean
  when?: string
  css: string
  className?: string
}
```

约定：

- `when` 为空表示无条件规则，始终生效；
- `when` 有值表示条件规则；
- `css` 是不带选择器的 CSS 声明块；
- `className` 是可选的 CSS 类名；
- 规则不设置名称；
- 条件规则在页面内直接编辑，不单独弹窗；
- CSS 脚本在页面内显示摘要，点击摘要或“编辑样式脚本”按钮后弹窗编辑。

卡片整体样式建议使用：

```ts
interface CardStyle {
  theme?: CardTheme
  base?: StyleRule
  rules?: StyleRule[]
}
```

字段样式建议使用：

```ts
interface FieldStyle {
  base?: StyleRule
  rules?: StyleRule[]
}
```

## 3. 卡片整体样式编辑器

入口为卡片组件属性面板中的“卡片样式脚本”按钮。

### 3.1 页面内布局

```text
卡片样式配置

预制样式
[ 默认 · 标准网格卡片                         ▼ ]

始终生效样式
┌──────────────────────────────────────────┐
│ background-color: #ffffff;              │
│ border-radius: 8px;                     │
│ padding: 16px;                          │
│ ...                                      │
└──────────────────────────────────────────┘
[编辑样式脚本]

条件样式
┌──────────────────────────────────────────┐
│ 启用 [✓]                                  │
│ 条件表达式 [?]                            │
│ [ $row.status === '异常'                 ]│
│                                          │
│ 命中样式                                  │
│ background-color: #fff1f0;               │
│ border-color: #f56c6c;                   │
│ [编辑样式脚本]                            │
│                                          │
│ CSS 类名                                 │
│ [ card-status-error                     ]│
│                                      [删除]│
└──────────────────────────────────────────┘

[+ 添加条件样式]

[取消] [确定]
```

页面内不直接放置完整 CSS 多行编辑框，只显示脚本摘要。摘要显示前 2～3 行，超出部分使用省略号；没有脚本时显示“未设置样式脚本”。

### 3.2 预制样式

预制样式下拉框提供 6 个选项：

- 默认 · 标准网格卡片；
- 紧凑 · 小号间距精简；
- 宽松 · 大间距舒适留白；
- 深色 · 暗色主题；
- 无边框 · 极简透明；
- 蓝色科技 · 霓虹科技风格。

“蓝色科技 · 霓虹科技风格”使用深蓝背景、亮蓝边框和冷色高对比文字，建议视觉参数为：

```ts
{
  backgroundColor: '#0f2747',
  borderColor: '#1677ff',
  hoverShadowColor: 'rgba(22, 119, 255, 0.45)',
  borderRadius: 8,
  padding: 16,
  gap: 16,
  titleFontSize: 16,
  titleFontWeight: 600,
  titleColor: '#e6f4ff',
  fieldFontSize: 14,
  fieldLabelColor: '#91caff',
  fieldValueColor: '#ffffff',
}
```

选择预制样式后，将该主题转换为 CSS 声明并写入“始终生效样式”的脚本内容。用户随后可以编辑脚本，编辑后的内容优先于原始预设内容。

### 3.3 条件表达式

条件表达式由用户手写，不提供条件字段、操作符和值的可视化拆分控件。

问号提示内容：

```text
请输入 JavaScript 条件表达式。

可用变量：
$row  当前数据行
row   当前数据行

示例：
$row.status === '异常'
$row.amount > 10000
$row.priority === '高' && $row.status !== '完成'

表达式返回 true 时，应用本规则样式。
```

整体条件规则主要使用 `$row` 判断当前行：

```ts
$row.status === '异常'
```

### 3.4 条件规则操作

每条规则包含：

- 启用开关；
- 条件表达式输入框；
- 命中样式脚本摘要；
- 编辑样式脚本按钮；
- CSS 类名输入框；
- 删除按钮。

点击“添加条件样式”时新增一条空规则：

```ts
{
  enabled: true,
  when: '',
  css: '',
  className: ''
}
```

确定时校验：

- 条件表达式不能为空；
- 命中样式脚本不能为空；
- 表达式无法求值时提示用户修正。

规则按列表顺序执行：跳过未启用规则，所有命中的规则都应用，后命中的同名 CSS 属性覆盖前面的属性，CSS 类名合并。

### 3.5 CSS 编辑弹窗

整体无条件样式和条件命中样式共用 CSS 编辑弹窗。弹窗根据来源显示作用范围：

```text
编辑始终生效样式脚本
作用范围：整张卡片
```

或：

```text
编辑条件命中样式脚本
作用范围：整张卡片
```

编辑器只接受 CSS 声明块：

```css
background-color: #fff1f0;
border-color: #f56c6c;
color: #f56c6c;
```

不要求也不建议填写选择器：

```css
.card-item {
  color: red;
}
```

## 4. 字段级样式编辑器

字段高级配置中保留字段本身的业务配置，例如字段角色、标签显示、标签位置和对齐方式；样式部分使用与整体样式相同的规则编辑方式。

### 4.1 页面内布局

```text
字段高级配置

基础设置
字段角色       [ 普通字段                  ▼ ]
显示标签       [✓]
标签位置       [ 左侧                    ▼ ]
对齐方式       [ 左对齐                  ▼ ]

字段样式

始终生效样式
┌──────────────────────────────────────────┐
│ color: #303133;                         │
│ font-weight: 600;                       │
│ ...                                      │
└──────────────────────────────────────────┘
[编辑样式脚本]

条件样式
┌──────────────────────────────────────────┐
│ 启用 [✓]                                  │
│ 条件表达式 [?]                            │
│ [ $value === '异常'                      ]│
│                                          │
│ 命中样式                                  │
│ color: #f56c6c;                          │
│ background-color: #fff1f0;               │
│ [编辑样式脚本]                            │
│                                          │
│ CSS 类名                                 │
│ [ status-error                          ]│
│                                      [删除]│
└──────────────────────────────────────────┘

[+ 添加条件样式]

[取消] [确定]
```

字段条件规则的作用范围是当前字段，不影响整张卡片。

### 4.2 条件表达式帮助

问号提示内容：

```text
请输入 JavaScript 条件表达式。

可用变量：
$value 当前字段值
$row   当前数据行
row    当前数据行

示例：
$value === '异常'
$row.status === '异常'
$row.amount > 10000

表达式返回 true 时，应用本规则样式。
```

### 4.3 字段 CSS 编辑弹窗

字段级 CSS 编辑弹窗显示：

```text
编辑字段样式脚本
作用范围：当前字段「状态」
```

内容仍然只填写 CSS 声明，不填写选择器。

## 5. 两种编辑器的差异

| 项目 | 卡片整体样式 | 字段级样式 |
|---|---|---|
| 作用范围 | 整张卡片 | 当前字段 |
| 预制样式 | 有 | 无 |
| 始终生效 CSS | 有 | 有 |
| 条件表达式 | 有 | 有 |
| CSS 脚本编辑 | 点击摘要弹窗 | 点击摘要弹窗 |
| CSS 类名 | 可选 | 可选 |
| 常用变量 | `$row`、`row` | `$value`、`$row`、`row` |
| 规则名称 | 无 | 无 |
| 条件规则单独弹窗 | 无 | 无 |

## 6. 数据流与执行规则

1. 打开编辑器时复制当前样式，避免直接修改外部配置；
2. 选择预制主题时生成并填充基础 CSS 脚本；
3. CSS 弹窗确认后只更新对应规则的 `css` 字段；
4. 整体样式确认后写回 `CardStyle`；
5. 字段样式确认后写回当前字段的 `FieldStyle`；
6. 渲染时先应用无条件规则；
7. 按规则顺序求值启用的条件规则；
8. 所有命中的条件规则合并到最终样式，后者覆盖同名属性；
9. `className` 合并到目标元素；
10. 条件表达式在现有脚本沙箱中执行，表达式错误时显示配置错误，不应导致页面白屏。

## 7. 验收标准

- 整体样式编辑器没有规则名称输入框；
- 字段样式编辑器没有规则名称输入框；
- 条件规则在主编辑器内直接显示和编辑；
- 条件表达式仅使用手写输入框；
- 条件表达式标签后存在 `?` 悬浮帮助；
- CSS 在主编辑器中显示摘要，点击后弹出编辑窗体；
- 选择预制主题会填充基础 CSS 脚本；
- 用户修改 CSS 后，重新打开编辑器能看到修改后的内容；
- 卡片整体条件可以根据 `$row` 控制整张卡片；
- 字段条件可以根据 `$value` 或 `$row` 控制当前字段；
- 多条命中规则按顺序合并，后者覆盖同名 CSS 属性；
- 整体规则不会错误地作用到单个字段，字段规则不会错误地作用到整张卡片。
