# 07 常见问题（管理侧）

## 账号与权限

**Q：用户忘记密码怎么办？**
系统管理 → 用户管理 → 该用户行内「重置密码」，把新密码单独告知本人。管理员自己的密码同样走用户管理重置（需要另一个管理员操作）。

**Q：用户登录了但左侧菜单是空的？**
按序查：① 用户是否停用状态；② 用户是否关联了角色；③ 角色的菜单权限树是否勾选了菜单。全部勾上后让用户重新登录。

**Q：改了角色权限，用户说没变化？**
权限在登录时加载，让用户退出重新登录（或刷新页面）后生效。

**Q：能看到菜单但点开 403 / 404？**
404：页面没挂菜单或菜单 path 被改过；403：权限标识对不上（常见于手工新建菜单时 `page:read:{页面key}` 填错）。细节见[开发手册 08 章](../dev/08-权限与菜单.md)。

## 组织与字典

**Q：人员调部门了，流程里还是旧部门？**
用户管理里更新所属机构；流程/表单已解析出的审批人不会回溯，让业务方发起前确认，或管理员协调转签。

**Q：字典删了一个选项，历史数据里的值还在吗？**
在。建议用「停用」代替删除，历史数据正常展示，只是新录入不再出现该选项。

## 消息

**Q：用户说没收到通知，怎么排查？**
① 消息中心 → 让用户查站内信（站内信不经过外部渠道，最先核对）；② 发送记录 → 有记录看状态：失败查渠道配置后重发；没记录查订阅规则是否覆盖该事件与接收人；③ 渠道整批失败 → 渠道配置参数过期（短信签名、企微凭证等）。

**Q：公告发了有人看不到？**
核对公告的范围与起止时间；让用户刷新首页/消息中心。

## 流程

**Q：单子卡住了，审批人离职了？**
见管理手册 05.3：补角色成员 → 协调转签；常态化问题让开发侧改审批人来源。

**Q：流程发起后表单填错了，能撤回吗？**
当前版本以审批「驳回」回到发起节点修改为主；实例级的终止/回滚属强干预，联系平台开发处理。

## AI

**Q：逻辑流 AI 节点报错？**
先到模型配置页核对：开关已启用、地址是 OpenAI 兼容端点、模型名正确、Key 有效（或内网网关免 Key）。用 [06 章](06-AI模型配置.md)的验证流程跑一条最小逻辑流定位。

**Q：换了网关地址，要不要重启？**
不用，保存即生效。
