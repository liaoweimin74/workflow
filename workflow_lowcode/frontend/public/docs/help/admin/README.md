## 通用约定

- 菜单按角色授权显示，看不到某菜单通常是角色未勾选（处理见 [01 章](01-用户与角色.md)）；
- 「启停」类操作在列表行内即可完成，删除类操作均有二次确认；
- 涉及发布/挂接的开发侧操作（建页面、挂菜单、模块迁移）见开发手册，本章只覆盖纯管理动作。
