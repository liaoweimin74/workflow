# 10 常见场景与 FAQ

本章是「配方集」：给目标，给配置路径。细节机制回各章查阅。

## 10.1 左树右表（按分类看列表）

1. 数据准备：分类表 + 业务表两个 FORM 数据源；业务数据源含分类外键列；
2. 画布拖入「树形数据」（绑分类数据源）与「数据表格」（绑业务数据源）；
3. 页面属性打开「动作总线」新建一条：触发器=树节点点击，步骤=`设置过滤`（target=业务数据源标识，field=分类外键列，value=`{node.id}` 或对应字段）+ `刷新数据`（同 target）；
4. 预览验证：点节点右表跟随过滤。
   要点：模板变量的根（`node`/`row`/`record`）随触发器不同，务必用配置面板下拉选变量，不要手打。

## 10.2 点击行 → 容器里编辑 → 保存回表

1. 画布：数据表格 + 数据容器（内含「数据录入」表单，绑同一 FORM 数据源）；记下容器的容器地址（表单容器字段名）；
2. 表格操作列加按钮，动作链依次：`加载记录`（target=容器地址，recordId=`$row.id`）、`打开容器`（target=容器地址）；
3. 容器表单自带或再加一个按钮挂 `保存容器` → `关闭容器` → `刷新数据`；
4. 用数据源浏览页先备几条测试数据再验。

## 10.3 导入 / 导出 Excel

- 导出：表格组件操作按钮选动作 `导出数据`（当前筛选条件与列都会带上）；
- 导入：页面表格的 Excel 导入入口，按列映射上传；映射不一致时先在数据源确认列名；
- 大批量导入建议分批，失败行会提示行号，修正后重传即可。

## 10.4 审批通过后自动落业务表

1. 业务数据用业务表单建模（有独立表）；
2. 审批填报用工作流表单；
3. 流程「审批通过」处触发逻辑流：用 `数据写入（upsert）` 按单号落到业务表，天然幂等；
4. 追加 `消息通知` 节点告知结果。表单事件绑定的语义与事务选择见 [06 章 6.4](06-逻辑编排.md#6.4)。

## 10.5 提交前校验/自动补全

「同一设备不允许有未关闭报修单」这类规则：

1. 写一条逻辑流：`数据查询`（按设备字段+状态过滤）→ `条件`（查到了就失败退出并带消息）；
2. 表单列表 →「逻辑流绑定」挂到 **BEFORE_CREATE**——前类触发点失败即拒绝提交，消息回给用户；
3. 自动编号想自定义规则，同样在前类触发点里生成回写。

## 10.6 数据看板页

组合拳：SQL/VQB 数据源做聚合集合，图表用「统计图 / KPI 指标卡 / 排行榜 / 目标进度」，实时性不高的接口型数据用 API 数据源 + 探测映射；页面级「另存为模板（骨架）」把看板沉淀成部门自助开页的模板（槽位起好锚点名，如「主指标」「明细列表」）。

## 10.7 FAQ 速查

| 现象 | 最可能原因 → 处理 |
| --- | --- |
| 发布成功但访问 404 | 页面没挂菜单 → 挂接菜单，见 [08.3](08-权限与菜单.md#8.3) |
| 有菜单入口但 403 | 角色未勾该菜单或未重新登录 → 08.6 排障清单 |
| 数据源建好页面里选不到 | 状态是草稿/停用 → 启用后再配 |
| WORKFLOW 数据源点新增报 400 | 该类型只读 → 用表单数据源或流程发起 |
| 总线/动作链里模板取值为空 | 根名与触发器不匹配（`{row}` vs `{node}` vs `$row.`）→ 用下拉候选 |
| 脚本动作没执行 | `VITE_PAGE_SCRIPT_ENABLED` 未开启 |
| 逻辑流绑定时下拉里没有 | 未发布，或入参与触发点不一致 → 设计器一键导入触发点参数 |
| 改完表单字段页面列没了 | 字段 key 是锚点，改名等于换列 → 页面里重选列 |
| 覆盖上传物料后页面空白 | 旧 bundle 已失效而浏览器缓存未刷 → 强刷；确认 manifest 的 key 未变 |
| 待办里找不到本该审批的单 | 审批人来源解析不到人（离职/角色空）→ 查节点审批人设置与无审批人策略 |
