# 卡片与字段样式编辑器 UI 修正设计

## 1. 修正范围

本次只调整样式编辑器的交互和布局，不改变已经确认的样式规则渲染语义。

涉及两个界面：

- 卡片样式配置；
- 卡片列表数据源配置中的字段高级设置。

## 2. 通用样式脚本编辑框

基础样式和条件命中样式都使用相同的编辑框：

```text
样式脚本
┌────────────────────────────────────────────┐
│ color: #303133;                         ✎ │
│ font-weight: 600;                         │
└────────────────────────────────────────────┘
```

要求：

- 编辑框本身可以直接输入和修改 CSS；
- 右侧固定显示编辑图标按钮；
- 点击图标打开 CSS 脚本弹窗；
- 弹窗确认后同步回编辑框；
- 编辑框修改后重新打开弹窗时显示最新内容；
- 没有内容时显示“未设置样式脚本”；
- CSS 只填写声明块，不填写选择器。

例如：

```css
background-color: #fff1f0;
border-color: #f56c6c;
color: #f56c6c;
```

## 3. 卡片样式配置

### 3.1 预设样式

预设下拉选项必须去重，只允许出现一次：

```text
默认 · 标准网格卡片
紧凑 · 小号间距精简
宽松 · 大间距舒适留白
深色 · 暗色主题
无边框 · 极简透明
蓝色科技 · 霓虹科技风格
```

“蓝色科技 · 霓虹科技风格”内部值统一为 `techBlue`。

预设选择后，将预设 CSS 填入基础“样式脚本”编辑框，用户可以直接修改，也可以通过右侧编辑图标打开弹窗修改。

### 3.2 页面布局

卡片整体样式页面采用顶部 label 和 24 栅格：

```text
卡片样式配置

预制样式
[ 默认 · 标准网格卡片                         ▼ ]

样式脚本
┌────────────────────────────────────────────┐
│ background-color: #ffffff;              ✎ │
│ border-radius: 8px;                       │
│ padding: 16px;                            │
└────────────────────────────────────────────┘

基础 class
[ el-card is-hover-shadow process-card         ]
提示：多个 class 使用空格分隔，不需要输入“.”。

条件样式
┌──────┬────────────────────┬──────────────────────┬──────────────────┬──────┐
│ 启用 │ 条件表达式 [?]     │ 命中样式脚本         │ CSS Class        │ 操作 │
├──────┼────────────────────┼──────────────────────┼──────────────────┼──────┤
│ ✓    │ $row.status ===    │ background-color... ✎│ status-error     │ 删除 │
│      │ '异常'             │                      │                  │      │
└──────┴────────────────────┴──────────────────────┴──────────────────┴──────┘

[+ 添加条件样式]

[取消] [确定]
```

规则：

- 预制样式独占 24 栅格；
- 样式脚本独占 24 栅格；
- 基础 class 独占 24 栅格；
- 条件样式表格独占 24 栅格；
- 不把预制样式、样式脚本、基础 class 强行放在同一行。

### 3.3 条件样式表格

条件规则不再使用大块规则卡片，改为紧凑表格：

| 列 | 内容 |
|---|---|
| 启用 | 开关 |
| 条件表达式 | 可直接输入的表达式，标签后有 `?` 帮助 |
| 命中样式脚本 | 可直接输入的脚本编辑框，右侧有编辑图标 |
| CSS Class | 空格分隔的多个 class |
| 操作 | 删除 |

条件表达式帮助：

```text
请输入 JavaScript 条件表达式。

可用变量：
$row 当前数据行
row 当前数据行

示例：
$row.status === '异常'
$row.amount > 10000
$row.priority === '高' && $row.status !== '完成'

表达式返回 true 时，应用本规则样式。
```

表格中不显示规则名称，条件表达式直接在表格单元格中编辑，不弹出独立规则窗体。

## 4. 字段高级设置

### 4.1 删除分组标题和分割线

移除以下视觉分组标题及分割横线：

- 动态内容；
- 列样式；
- 字段样式；
- 单元格点击事件（配置后优先于整表级点击）。

逻辑分组仍然保留，但通过间距和栅格布局区分，不使用 `el-divider`。

### 4.2 页面布局

所有控件采用顶部 label，label 和 input 上下排列：

[ 表达式 ] [ 模板 ] [ 无 ]

[ 左侧                    ▼ ]

│ color: #303133;                         ✎ │
│ font-weight: 600;                         │
└────────────────────────────────────────────┘

基础 class
[ status-value text-primary                    ]
提示：多个 class 使用空格分隔，不需要输入“.”。

条件样式
┌──────┬────────────────────┬──────────────────────┬──────────────────┬──────┐
│ 启用 │ 条件表达式 [?]     │ 命中样式脚本         │ CSS Class        │ 操作 │
├──────┼────────────────────┼──────────────────────┼──────────────────┼──────┤

### 4.3 字段样式内容

将“始终生效样式”改名为：

```text
样式脚本
```

字段样式脚本和条件命中脚本都使用通用“可直接输入 + 右侧编辑图标”的编辑框。

基础 class 必须使用独立 label：

```text
基础 class
[ status-value text-primary ]
```

多个 class 使用空格分隔，不要求输入 `.`。

### 4.4 字段条件样式表格

字段条件样式使用与卡片整体相同的表格结构：

```text
┌──────┬────────────────────┬──────────────────────┬──────────────────┬──────┐
│ 启用 │ 条件表达式 [?]     │ 命中样式脚本         │ CSS Class        │ 操作 │
├──────┼────────────────────┼──────────────────────┼──────────────────┼──────┤
│ ✓    │ $value === '异常'  │ color: #f56c6c;   ✎ │ status-error     │ 删除 │
└──────┴────────────────────┴──────────────────────┴──────────────────┴──────┘
```

字段条件帮助：

```text
请输入 JavaScript 条件表达式。

可用变量：
$value 当前字段值
$row 当前数据行
row 当前数据行

示例：
$value === '异常'
$row.status === '异常'
$row.amount > 10000

表达式返回 true 时，应用本规则样式。
```

## 5. 栅格规则

使用 24 栅格：

```css
.cfg-row {
  display: grid;
  grid-template-columns: repeat(24, minmax(0, 1fr));
  gap: 16px;
}
```

允许并排的同组控件：

- 角色 + 值类型：各占 12 栅格；
- 对齐方式 + 显示标签：各占 12 栅格；
- 标签位置可与显示标签同组并排，或独占一行。

必须独占整行的内容：

- 预制样式；
- 样式脚本；
- 基础 class；
- 条件样式表格；
- 点击动作；
- 动态内容中的长表达式输入框。

不同语义组不得为了填充空间而放在同一行。

## 6. 验收标准

- 蓝色科技预设在下拉中只出现一次；
- 卡片和字段条件样式均使用紧凑表格；
- 规则不显示名称；
- 条件表达式直接在表格中输入；
- 条件表达式后有 `?` 悬浮帮助；
- CSS 脚本编辑框可以直接输入；
- CSS 脚本编辑框右侧有编辑图标；
- 点击编辑图标打开 CSS 弹窗；
- 编辑框与弹窗内容双向同步；
- 字段界面移除指定的分组标题和分割横线；
- 字段“始终生效样式”显示为“样式脚本”；
- 字段基础 class 有明确 label；
- label 与 input 上下排列；
- 同组字段可以并排，不同语义组不会被强行并排；
- 表格和脚本编辑框左右边缘对齐；
- 不改变整体样式、字段样式和表格/CELL 的既有渲染语义。
