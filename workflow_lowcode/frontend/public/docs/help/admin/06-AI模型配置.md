# 06 AI 模型配置

入口：**系统管理 → 模型配置**。这里是全平台 AI 能力的总开关与总配置。

## 6.1 配置项

| 项 | 说明 |
| --- | --- |
| 启用大模型 | 总开关，关闭后所有 AI 功能不响应 |
| 服务地址 | 大模型网关地址（OpenAI 兼容协议，`/chat/completions`） |
| API Key | 仅脱敏展示、不回传明文；留空保持不变；输入 `-` 可清除；部分内网网关可留空 |
| 模型名称 | 必填，如 `gpt-4o-mini` 或网关侧的模型标识 |

**保存即生效，无需重启**。

### 与部署环境变量的优先级

| 情形 | 生效来源 |
| --- | --- |
| 页面保存过（哪怕只一次） | 以本页配置为准，包括「启用大模型」开关 |
| 从未在本页保存过 | 回退部署时的 `workflow.ai.*`（`AI_BASE_URL`/`AI_API_KEY`/`AI_MODEL`）默认值 |

页面顶部的「来源」一行会写明当前取的是哪一份。在本页配好模型后，即使部署时设了 `WORKFLOW_AI_ENABLED=false`（那只是关掉内置网关默认值），AI 助手等能力照常可用。

## 6.2 配置的作用范围

平台内所有消费大模型的功能共用这一份配置：

- 逻辑流的「AI 大模型」节点；
- AI 对话、AI 助手；
- 表单 AI 生成/填充等 AI 能力。

## 6.3 验证配置是否生效

1. 保存配置；
2. 打开 **开发管理 → 逻辑流**，新建或编辑一条草稿逻辑流，拖入「AI 大模型」节点，写一句简单 prompt（如「回答：1+1=?」），用「运行测试」执行；
3. 节点返回模型文本即接入成功；失败按返回信息核对地址、Key、模型名。

## 6.4 注意事项

- 仅支持 OpenAI 兼容协议，第三方网关需提供兼容端点；
- API Key 属敏感信息，不要写进文档/截图/聊天记录，配置面板也只回显掩码；
- 内网环境优先走内网网关（可免 Key），避免数据出网；
- 模型响应变慢或超时，多为网关侧问题，先在网络层排查再调整逻辑流节点的超时设置。
