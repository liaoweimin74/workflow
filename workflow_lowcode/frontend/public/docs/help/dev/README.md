# 开发手册

| --- | --- | --- |

| [02 新手入门](02-新手入门.md) | 从零做出第一个可访问的业务页面 | 第一次使用平台 |
| [03 表单设计](03-表单设计.md) | 表单设计器、组件、校验、字段权限 | 数据建模 |
| [04 页面与数据源](04-页面与数据源.md) | 数据源、自定义页面、动作总线与事件链、页面模板 | 界面搭建 |
| [05 流程编排](05-流程编排.md) | BPMN 工作流：节点、会签、超时、版本部署 | 审批类业务 |

## 建议阅读路线

- **快速上手**：01 → 02，跟着做完一遍示例。
- **做审批业务**：03 → 05 → 08。
- **做数据看板/复杂交互**：04 → 06 → 10。
- **多环境交付（开发→测试→生产）**：07 模块管理。
- **设计器做不了的需求**：先翻 [10 章](10-常见场景与FAQ.md)场景配方，再按 [09 章](09-自定义开发.md)写代码。
